Fast Bean Copier 快速入门指南

v1.3.2 新特性：嵌套对象深拷贝 - 自动处理不同类型的嵌套对象转换（如 Address → AddressDto），智能检测 Copier 类并优化性能。

v1.3 新特性：更新现有对象（updateDto/updateEntity）、映射前回调（beforeMapping）、条件映射（condition）、默认值和常量（defaultValue/constant）、全局配置（@CopyTargetConfig）、Null 值处理策略（NullValueStrategy）。

5 分钟快速开始

步骤 1：添加依赖

在您的 pom.xml 中添加以下依赖：

<dependency>
    <groupId>com.github.jackieonway</groupId>
    <artifactId>fast-bean-copier-annotations</artifactId>
    <version>1.3.2</version>
</dependency>

<dependency>
    <groupId>com.github.jackieonway</groupId>
    <artifactId>fast-bean-copier-processor</artifactId>
    <version>1.3.2</version>
    <scope>provided</scope>
</dependency>

步骤 2：定义源类

public class User {
    private Long id;
    private String name;
    private String email;
    private Integer age;
    
    // getter/setter...
    public Long getId() { return id; }
    public void setId(Long id) { this.id = id; }
    
    public String getName() { return name; }
    public void setName(String name) { this.name = name; }
    
    public String getEmail() { return email; }
    public void setEmail(String email) { this.email = email; }
    
    public Integer getAge() { return age; }
    public void setAge(Integer age) { this.age = age; }
}

步骤 3：定义 DTO 类

import com.github.jackieonway.copier.annotation.CopyTarget;

@CopyTarget(source = User.class)
public class UserDto {
    private Long id;
    private String name;
    private String email;
    private Integer age;
    
    // getter/setter...
    public Long getId() { return id; }
    public void setId(Long id) { this.id = id; }
    
    public String getName() { return name; }
    public void setName(String name) { this.name = name; }
    
    public String getEmail() { return email; }
    public void setEmail(String email) { this.email = email; }
    
    public Integer getAge() { return age; }
    public void setAge(Integer age) { this.age = age; }
}

步骤 4：编译

mvn clean compile

编译完成后，Fast Bean Copier 会自动生成 UserDtoCopier 类。

步骤 5：使用

// 创建源对象
User user = new User();
user.setId(1L);
user.setName("张三");
user.setEmail("zhangsan@example.com");
user.setAge(25);

// 转换为 DTO
UserDto userDto = UserDtoCopier.toDto(user);

// 打印结果
System.out.println("ID: " + userDto.getId());
System.out.println("Name: " + userDto.getName());
System.out.println("Email: " + userDto.getEmail());
System.out.println("Age: " + userDto.getAge());

常见场景

场景 1：忽略敏感字段

@CopyTarget(source = User.class, ignore = {"password"})
public class UserDto {
    private Long id;
    private String name;
    private String email;
    // password 字段不会被拷贝
}

场景 2：批量转换

List<User> users = userRepository.findAll();
List<UserDto> userDtos = UserDtoCopier.toDtoList(users);

场景 3：双向转换

// 从 DTO 转换为实体
User user = UserDtoCopier.fromDto(userDto);

// 保存到数据库
userRepository.save(user);

// 再转换回 DTO
UserDto response = UserDtoCopier.toDto(user);

场景 4：集合转换

// List 转换
List<UserDto> dtos = UserDtoCopier.toDtoList(users);

// Set 转换
Set<UserDto> dtoSet = UserDtoCopier.toDtoSet(users);

// 反向转换
List<User> users = UserDtoCopier.fromDtoList(dtos);
Set<User> userSet = UserDtoCopier.fromDtoSet(dtoSet);

场景 5：嵌套对象深拷贝（v1.3.2 新增）

自动处理不同类型的嵌套对象转换：

// 实体类
public class Employee {
    private Long id;
    private String name;
    private Address address;  // 嵌套对象
}

// DTO 类 - 嵌套对象类型不同
@CopyTarget(source = Employee.class)
public class EmployeeDto {
    private Long id;
    private String name;
    private AddressDto address;  // 不同类型的嵌套对象
}

// 如果 AddressDto 有 @CopyTarget 注解，自动使用 AddressDtoCopier（最优性能）
@CopyTarget(source = Address.class)
public class AddressDto {
    private String city;
    private String street;
}

// 使用
Employee employee = new Employee(1L, "张三", new Address("北京", "朝阳区"));
EmployeeDto dto = EmployeeDtoCopier.toDto(employee);
// dto.address 自动转换为 AddressDto 类型

// 如果 AddressDto 没有 @CopyTarget 注解，自动使用字段级拷贝（无需额外配置）

场景 6：集合深拷贝（嵌套对象）

Order order = new Order(1L,
        Arrays.asList("paid", "delivered"),
        Collections.singletonList(new User(1L, "Tom", "tom@test.com", 20)));

OrderDto orderDto = OrderDtoCopier.toDto(order);
List<OrderDto> orderDtos = OrderDtoCopier.toDtoList(Collections.singletonList(order));

// 反向转换
Order restored = OrderDtoCopier.fromDto(orderDto);
List<Order> restoredList = OrderDtoCopier.fromDtoList(orderDtos);

场景 7：数组与 Map 深拷贝

ArrayHolder holder = new ArrayHolder(

v1.2 新功能

多对一映射

@CopyTarget(source = Person.class)
public class PersonDto {
    @CopyField(source = {"firstName", "lastName"}, 
               expression = "java(source.getFirstName() + \" \" + source.getLastName())")
    private String fullName;
}

一对多映射

@CopyTarget(source = FullNameSource.class)
public class NameDto {
    @CopyField(source = "fullName", 
               expression = "java(source.getFullName().split(\" \")[0])")
    private String firstName;
}

数字格式化

@CopyField(converter = NumberFormatter.class, format = "#,##0.00元")
private String priceText;  // 1234.5 -> "1,234.50元"

日期格式化

@CopyField(converter = DateFormatter.class, format = "yyyy-MM-dd HH:mm:ss")
private String createTimeText;  // LocalDateTime -> "2025-12-29 10:30:00"

自定义转换器

@CopyTarget(source = Person.class, uses = PersonConverter.class)
public class PersonDto {
    @CopyField(qualifiedByName = "formatAge")
    private String ageText;
}

Spring 集成

@CopyTarget(source = User.class, componentModel = ComponentModel.SPRING)
public class UserDto { }

@Service
public class UserService {
    @Autowired
    private UserDtoCopier userDtoCopier;
    
    public UserDto convert(User user) {
        return userDtoCopier.toDto(user);
    }
}

函数式定制（v1.3.1 统一行为）

v1.3.1 重要变更：所有集合类型的 customizer 现在都操作整个集合，提供一致且强大的定制能力。

// 单对象定制
UserDto dto = UserDtoCopier.toDto(user, result -> {
    result.setDisplayName(result.getName().toUpperCase());
    return result;
});

// List 定制 - 过滤、排序、限制（v1.3.1 统一行为）
List<UserDto> filteredList = UserDtoCopier.toDtoList(users, list -> 
    list.stream()
        .filter(dto -> dto.getPrice() >= 100)
        .sorted(Comparator.comparing(UserDto::getName))
        .limit(10)
        .collect(Collectors.toList())
);

// Set 定制 - 转换为不可变集合（v1.3.1 统一行为）
Set<UserDto> immutableSet = UserDtoCopier.toDtoSet(userSet, 
    Collections::unmodifiableSet
);

// Map 定制 - 过滤条目（v1.3.1 新增）
Map<String, UserDto> filteredMap = UserDtoCopier.toDtoMap(userMap, map -> {
    map.entrySet().removeIf(entry -> entry.getValue() == null);
    return map;
});

// Array 定制 - 排序（v1.3.1 新增）
UserDto[] sortedArray = UserDtoCopier.toDtoArray(users, array -> {
    Arrays.sort(array, Comparator.comparing(UserDto::getName));
    return array;
});

v1.3 新功能

更新现有对象

// 更新已存在的 DTO 对象
UserDto existingDto = new UserDto();
existingDto.setName("原始名称");
UserDtoCopier.updateDto(existingDto, user);
// existingDto 的字段被更新为 user 的值

// 反向更新实体对象
User existingUser = new User();
UserDtoCopier.updateEntity(existingUser, userDto);

映射前回调

@CopyTarget(source = User.class, beforeMapping = "validateAndPrepare")
public class UserDto {
    private Long id;
    private String name;
    
    // 映射前回调方法（必须是 default 方法）
    default void validateAndPrepare(User source) {
        if (source.getName() == null) {
            throw new IllegalArgumentException("Name cannot be null");
        }
    }
}

条件映射

@CopyTarget(source = User.class)
public class UserDto {
    // 只有当源字段不为 null 时才执行映射
    @CopyField(condition = "java(source.getName() != null)")
    private String name;
    
    // 复杂条件
    @CopyField(condition = "java(source.getAge() != null && source.getAge() > 0)")
    private Integer age;
}

默认值

@CopyTarget(source = User.class)
public class UserDto {
    // 当源字段为 null 时使用默认值
    @CopyField(defaultValue = "未知")
    private String name;
    
    @CopyField(defaultValue = "0")
    private Integer age;
}

常量值

@CopyTarget(source = User.class)
public class UserDto {
    // 直接设置常量值，不依赖源字段
    @CopyField(constant = "SYSTEM")
    private String createdBy;
    
    @CopyField(constant = "1.3.0")
    private String version;
}

全局配置（v1.3/v1.3.1）

方式 1：包级别配置（v1.3）

// package-info.java
@CopyTargetConfig(
    componentModel = ComponentModel.SPRING,
    nullValueStrategy = NullValueStrategy.IGNORE
)

fast.bean.copier.componentModel=SPRING

配置优先级：类级别 > 包级别 > 配置文件 > 默认值

Null 值处理策略

// IGNORE：忽略 null 值，不更新目标字段（默认）
// REPLACE：替换 null 值，将目标字段设置为 null

@CopyTargetConfig(nullValueStrategy = NullValueStrategy.REPLACE)
package com.example.dto;

故障排除

问题：生成的 Copier 类未出现

解决方案：

  1. 确保使用了 @CopyTarget 注解
  2. 确保源类和目标类都有 getter/setter 方法
  3. 运行 mvn clean compile 进行完整编译

问题：字段未被拷贝

解决方案：

  1. 检查字段名是否完全相同（区分大小写）
  2. 检查源类和目标类是否都有该字段的 getter/setter
  3. 检查该字段是否在 ignore 属性中

问题：IDE 中看不到生成的代码

解决方案：

  1. 在 IDE 中刷新项目（F5 或右键 -> Refresh）
  2. 重新构建项目（Clean -> Build）
  3. 检查 IDE 是否启用了注解处理（通常默认启用）
